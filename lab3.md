# ЗВІТ
### з лабораторної роботи №3
**Тема:** Робота з умовами в розмітці. Застосування конструкцій if-else для зміни візуального оформлення елементів сторінки  
**Студентка:** Петренко Кіра  
**Група:** КН-25  

---

### 1. Мета роботи
Навчитися застосовувати керуючі конструкції логіки (`if/else`) при виведенні HTML-коду для створення динамічного UI на основі PHP-змінних, а також використовувати тернарний оператор для динамічного перемикання CSS-класів.

---

### 2. Технологічний стек
* **Мова програмування / Сервер:** PHP 8.3 (XAMPP / Apache)
* **Розмітка та Стилі:** HTML5, CSS3
* **Середовище розробки:** Visual Studio Code

---

### 3. Хід виконання роботи

1. **Оголошення логічної змінної:**
   У блоці ініціалізації додано логічну змінну `$isCompleted`:

```php
<?php
  $appName = "Task Manager";
  $taskTitle = "Вивчити основи PHP";
  $taskTimeEstimate = 2;
  $isCompleted = false;
?>
Використання альтернативного синтаксису if-else у розмітці:
Для відображення текстового статусу завдання використано синтаксис <?php if (...): ?> ... <?php else: ?> ... <?php endif; ?>:

HTML
<?php if ($isCompleted): ?>
    <span>✔️ Виконано</span>
<?php else: ?>
    <span>🕒 В процесі</span>
<?php endif; ?>
Динамічне призначення CSS-класу через тернарний оператор:
В атрибут class елемента <li> вбудовано тернарний оператор, який перемикає клас між .task-done та .task-pending:

HTML
<li class="<?= $isCompleted ? 'task-done' : 'task-pending' ?>">
